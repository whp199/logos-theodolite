Take a layer of the census

Gemma-4-31B. Every MLP neuron of a layer pushed along its own direction and read against 2,048 random ones. Layer 45 is done; layers 40–44 and 46–50 are open.

what you need

  • one NVIDIA card, 32 GB or more (5090, PRO 6000, A6000, 6000 Ada, A100, H100…); 24 GB cannot fit it
  • a CUDA 13 driver (580+), Linux
  • about 60 GB of disk, 32 GB of memory
  • about 13 hours a layer on a 5090, plus an hour of setup; it stops and resumes

No account, token or payment. Leave the machine otherwise quiet while it runs.

do this

  1. git clone https://github.com/whp199/logos-theodolite
cd logos-theodolite && git checkout census-kit-1
scripts/volunteer/census.sh check
  2. scripts/volunteer/census.sh reserve 47 --name you

    Pick an open layer on the board. Post the CENSUS RESERVE line it prints, in the thread or on the board issue, and wait to see it on the board.

  3. scripts/volunteer/census.sh setup

    The pinned venv, Google's checkpoint, the lens files and the stats index, all under ~/theodolite-census.

  4. scripts/volunteer/census.sh canary 47

    One batch set against our card's: the same bits, or a card class of its own. Both are fine.

  5. scripts/volunteer/census.sh run 47

    Post the START line. It runs detached. If it stops, the same command continues it answer for answer.

  6. scripts/volunteer/census.sh status 47

    Post a PROGRESS line now and then; it keeps your claim.

  7. scripts/volunteer/census.sh pack 47

    About 500 MB in outbox/. Upload it anywhere that keeps it a week. Post the DONE line with the link.

the rules

  • one layer at a time; claim it first
  • change nothing: code, settings, batch (it refuses to run off the kit's tag)
  • one card from start to finish
  • a claim holds 36 h to START, then until your PROGRESS end time plus 24 h; 10 days at most
  • can't finish? census.sh release 47, post the line

how it is checked

  • every setting and all 565,254 answers, the claim's secret, the commit
  • 5 of the run's 737 chunks, drawn after it arrives, written again on our 5090
  • same bits as ours: must match exactly; another card: rules fixed beforehand (first word-piece, log-probabilities)
  • you send the answers, your card's name and versions, a claim code; no logs or paths

Full guide: github.com/whp199/logos-theodolite, VOLUNTEERS.md. Board: the pinned Census layer board issue. Layers count from 0 (the app's page = layer + 1).
